Usage: insforge storage [options] [command]

Manage storage

Options:
  -h, --help                       display help for command

Commands:
  buckets                          List all storage buckets
  create-bucket [options] <name>   Create a new storage bucket
  delete-bucket <name>             Delete a storage bucket and all its objects
  list-objects [options] <bucket>  List objects in a storage bucket
  upload [options] <file>          Upload a file to a storage bucket
  download [options] <objectKey>   Download a file from a storage bucket
  help [command]                   display help for command
